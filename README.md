# Border Forge v3 plus guides

This package includes the working map, blitz and fortification game plus an integrated help page, Quick Start, Manual and both PDFs.

INSTALL
Extract this ZIP to a NEW folder. Upload all 25 enclosed files (not the ZIP or enclosing folder) to the ROOT of juggler47-hue/borderforge-controller-test. Commit. In the existing Render service choose Manual Deploy > Deploy latest commit. Keep existing service settings. Refresh computer and phone. Check for v3 + GUIDES and Help & guides links.

Share this welcome page after deployment:
https://borderforge-controller-test.onrender.com/help.html

Other routes:
/ is the computer game
/controller.html is the phone controller
/quick-start.html and /manual.html are readable guides
/quick-start.pdf and /manual.pdf are printable downloads

Guides open in new tabs from the game so the current game stays open. Close the guide tab to return to an active game. Do not open another host game when trying to return to an existing campaign.
